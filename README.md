# Bad Apple 终端播放器

在终端里播放 Bad Apple。

## 环境要求
该程序已经对环境依赖进行了尽可能的优化，但为了保证功能完整，还是舍弃了一部分兼容性。

- Windows 10/11：Windows Terminal和传统cmd支持。 
- Windows 7/8.1：由于程序依赖的 `ANSI 转义序列` 在此版本Windows的终端上不支持，所以请自行安装别的现代终端。
- Linux / macOS：任何现代终端，且由于 `aplay/afplay` 的部分功能兼容性，不保证声音功能的稳定。
- 终端字体需要支持 Unicode `U+2800` 区，才能保证模式 3 正常显示。

## 按键

| 按键   | 功能                          |
|--------|-------------------------------|
| 空格   | 暂停 / 继续                   |
| Q / Esc| 退出                          |
| 左 / 右| 上一帧 / 下一帧               |
| R      | 从头重播                      |
| 1 ~ 5  | 跳到 20% / 40% / 60% / 80% / 100% |
| M      | 切换渲染模式                  |
| H      | 切换调试信息与窗口标题        |

按 `Q` 或 `Esc` 即可退出，程序会恢复终端状态（光标、颜色、备用屏幕）。

## 渲染模式

| 编号 | 名称       | 说明                                       |
|------|------------|--------------------------------------------|
| 0    | 半角块     | 纯黑白块，看着最舒服，每格 1x2 像素        |
| 2    | 密度阶梯   | 10 级灰度，柔和，虚化和星点表现最好        |
| 3    | 盲文点阵   | 每格 2x4 点，分辨率最高，字体需支持        |

模式 1 和 4 已移除，`mode_mask` 的可用位只剩 `0b1101`（即十进制 13）。
可通过更改 `config.json` 里的 `mode_mask` 来控制可用模式。

## 画质与帧率

`assets/frames.bin` 内是 240x180、60fps 的灰度帧（4bit 量化 + RLE 压缩），
播放时按需解码单帧，因此内存占用只有几百 KB，不会因为分辨率提高而爆内存。

渲染时用面积（盒式）采样把源帧映射到终端的子像素网格上，所以画面在放大的时候
边缘平滑、不会出现逐帧抖动的锯齿，小星点也不会被抽掉。

`fps` 控制每秒刷新（重绘）次数。源素材是 60fps，所以：

| fps | 适合情况                                       |
|-----|------------------------------------------------|
| 30  | 默认，绝大多数设备都无压力                     |
| 60  | 和源素材一致，动作最顺，推荐                       |
| 120 | 只是把帧边界对齐得更准，肉眼提升有限           |
| 144 | 同上，144Hz 屏幕可用                           |

帧号是以音频时间为准推进的，`fps` 越高，画面换帧的时刻就越贴近真实时间。
画面没有变化时不会重绘，所以高 fps 并不会等比放大 CPU 占用。
同理，源素材只有 60fps，所以 `fps` 设成 120 / 144 时画面刷新上限仍然是 60 次/秒，
只是每次换帧的时刻更精确（抖动更小）。

节拍依赖系统定时器精度：Windows 10 1803+ 会启用高精度可等待定时器，
144fps 下 CPU 占用仍只有 1% 左右；老系统或创建失败时自动退化为「睡眠 + 自旋」，
此时高刷新率会更吃 CPU，帧率上限也可能略低于设定值。

## 配置

编辑 `config.json` 以更改配置。

| 字段                   | 默认 | 说明                              |
|------------------------|------|-----------------------------------|
| `threshold`            | 128  | 二值化阈值，0~255                 |
| `mode`                 | 0    | 起始渲染模式                      |
| `mode_mask`            | 13   | 可用模式位掩码(13 = 模式 0/2/3)   |
| `fps`                  | 30   | 刷新率，建议 30 / 60 / 120 / 144  |
| `show_hud`             | 0    | 显示左上角调试信息                |
| `audio`                | 1    | 是否播放音频                      |
| `jump_keeps_pause`     | 0    | 暂停时跳转是否保持暂停            |
| `window_title`         | 1    | 是否动态设置窗口标题              |
| `progress_bar`         | 0    | 底部进度条                        |
| `fade_in` / `fade_out` | 0    | 淡入 / 淡出                       |
| `fade_frames`          | 30   | 淡入淡出帧数                      |
| `loop`                 | 1    | 播放完自动重播                    |
| `jump_flash`           | 0    | 跳转时闪烁反馈                    |
| `jump_flash_frames`    | 8    | 闪烁持续帧数                      |
| `intro_rain`           | 0    | 开场噪声收敛                      |
| `intro_frames`         | 30   | 开场持续帧数                      |
| `subtitle`             | 0    | 歌词字幕，0=关 1=日文 2=中文      |
| `subtitle_info`        | 0    | 人物介绍字幕，0=关 1=开           |

## 字幕

字幕默认关闭，把 `subtitle` 设成 `1` 或 `2`、`subtitle_info` 设成 `1` 即可打开。

| 文件                            | 内容           |
|---------------------------------|----------------|
| `assets/subtitles/lyrics_ja.srt`| 日文歌词       |
| `assets/subtitles/lyrics_zh.srt`| 中文歌词       |
| `assets/subtitles/characters.srt`| 人物介绍      |

字幕是标准 SRT 格式，时间轴直接对应音频时间（毫秒），自己改素材只要替换同名文件即可。
显示位置在最后一行（开启 `progress_bar` 时在进度条上方），居中，超宽会自动截断。

## 从源码编译

Windows 需要 MinGW64，Linux / macOS 用系统 g++。

    mingw32-make          # Windows
    make                  # Linux / macOS

你也可以直接从 [Release](https://github.com/Dray-zyc/BadApple-Terminal/releases) 中下载可执行文件

## 重新生成帧素材

`assets/frames.bin` 已经随仓库提供，一般不需要动它。只有想换分辨率或帧率时才需要：

    make raw          # 用 ffmpeg 从 assets/bad_apple.mp4 导出 assets/frames.raw
    make preprocess   # 打包成 assets/frames.bin

`raw` 目标默认导出 240x180、60fps、灰度；`preprocess` 会做 4bit 量化 + RLE 打包。
也可以脱离 Makefile 直接用参数运行，参数依次为 `输入raw 输出bin 宽 高 帧率`：

    tools/preprocess.exe assets/frames.raw assets/frames.bin 320 240 60
