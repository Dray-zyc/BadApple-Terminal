# Bad Apple 终端播放器

在终端里播放 Bad Apple。

## 环境要求
该程序已经对环境依赖进行了尽可能的优化，但为了保证功能完整，还是舍弃了一部分兼容性。

- Windows 10/11：Windows Terminal和传统cmd支持。 
- Windows 7/8.1：由于程序依赖的 `ANSI 转义序列` 在此版本Windows的终端上不支持，所以请自行安装别的现代终端。
- Linux / macOS：任何现代终端，且由于 `aplay/afplay` 的部分功能兼容性，不保证声音功能的稳定。
- 终端字体需要支持 Unicode `U+2800` 区，才能保证部分功能稳定。

## 按键

| 按键   | 功能                          |
|--------|-------------------------------|
| 空格   | 暂停 / 继续                   |
| Q / Esc| 退出                          |
| 左 / 右| 上一帧 / 下一帧               |
| R      | 从头重播                      |
| 1 ~ 5  | 跳到 20% / 40% / 60% / 80% / 100% |
| M      | 切换渲染模式                  |
| H      | 切换调试信息与窗口标题        |

## 渲染模式

| 编号 | 名称       | 说明                          |
|------|------------|-------------------------------|
| 0    | 半角块     | 经典，分辨率高                |
| 1    | 全角块     | 粗犷，画质低                  |
| 2    | 密度阶梯   | 10 级灰度，柔和               |
| 3    | 盲文点阵   | 分辨率最高，字体需支持        |
| 4    | 彩色描边   | 边缘染青色，视觉冲击强        |

可通过更改 `config.json` 里的 `mode_mask` 来控制。

## 配置

编辑 `config.json` 以更改配置。

| 字段                   | 默认 | 说明                              |
|------------------------|------|-----------------------------------|
| `threshold`            | 128  | 二值化阈值，0~255                 |
| `mode`                 | 0    | 起始渲染模式                      |
| `mode_mask`            | 31   | 可用模式位掩码(5位)                    |
| `fps_cap`              | 60   | 主循环轮询频率                    |
| `show_hud`             | 0    | 显示左上角调试信息                |
| `audio`                | 1    | 是否播放音频                      |
| `jump_keeps_pause`     | 0    | 暂停时跳转是否保持暂停            |
| `window_title`         | 1    | 是否动态设置窗口标题              |
| `progress_bar`         | 0    | 底部进度条                        |
| `fade_in` / `fade_out` | 0    | 淡入 / 淡出                       |
| `fade_frames`          | 30   | 淡入淡出帧数                      |
| `loop`                 | 1    | 播放完自动重播                |
| `jump_flash`           | 0    | 跳转时闪烁反馈                    |
| `jump_flash_frames`    | 8    | 闪烁持续帧数                      |
| `intro_rain`           | 1    | 开场噪声收敛                      |
| `intro_frames`         | 30   | 开场持续帧数                      |

## 从源码编译

Windows 需要 MinGW64，Linux / macOS 用系统 g++。

    mingw32-make          # Windows
    make                  # Linux / macOS
